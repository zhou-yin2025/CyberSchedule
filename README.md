## ✨ 核心特点

### 🖥️ 赛博空间架构
- **多悬浮窗交互**：屏幕上的每一个面板（任务栏、日历、状态栏等）都是独立的悬浮窗，支持**自由拖动**、**自动隐藏**、**贴边吸附**。
- **像素级视觉渲染**：所有界面均为 `QPainter` 自绘，完全不依赖原生控件样式，精确到每一个像素的霓虹光效。
- **粒子特效系统**：窗口启动、任务完成、状态变化时触发**像素潮汐冲刷**动画，提供极致的视觉反馈。

### 🎮 游戏化角色养成
- **动态状态栏**：左上角的六边形头像框包含`经验值（EXP）`、`口渴值（Hydration）`、`系统负载（Load）`。
- **实时反馈**：完成番茄钟或任务会获得经验值并触发升级弹跳动画；口渴值过低会闪烁警告；系统负载过高会导致界面产生故障特效（Glitch Effect）。
- **自定义外观**：支持双击更换头像、自定义昵称。

### ⚡ 高效任务管理
- **双形态任务栏**：
  - **收缩模式**：极简悬浮条，仅显示最近3个任务。
  - **展开模式**：完整面板，支持按日期分组、优先级排序、分类筛选。
- **全功能面板**：新建任务支持标题、四级优先级、截止日期、自定义分类。
- **快捷操作**：支持“延后一天”、“延后一项”、“关联番茄钟”。
- **日历联动**：日历视图自动标记任务截止日（根据优先级着色），点击日期即可筛选当天任务。

### ⏳ 番茄钟与音乐
- **专注计时器**：支持自定义工作/休息时长及循环次数，HUD 实时显示倒计时和当前任务名。
- **系统音频联动（SMTC）**：可读取系统正在播放的音乐，支持在桌面显示歌词、控制播放，或根据番茄钟状态自动调整音量。

## 🧩 功能一览

| 模块 | 功能说明 |
| :--- | :--- |
| **任务栏** | 增删改查、四色优先级、分类筛选、按时间/优先级/编号排序、收缩/展开动画 |
| **番茄钟** | 工作/休息倒计时、循环模式、预设配置、与任务关联 |
| **日历** | 月历视图、任务底色标记、点击日期联动筛选、缩放动画 |
| **状态栏** | 经验值（升级曲线）、口渴值（喝水提醒）、系统负载（散热）、头像/昵称自定义 |
| **便签** | 自动保存、贴边隐藏、钉子锁定 |
| **座右铭** | 透明悬浮文字，天蓝色霓虹，支持自定义 |
| **设置面板** | 调整口渴速率、负载间隔、外观（灯线速度/方向）、开机自启动 |
| **动画特效** | 像素潮汐冲刷、扫描线、灯线流动、全局电路背景 |
| **数据持久化** | SQLite 本地数据库，自动保存所有状态、任务、便签和配置 |

## 🛠️ 技术栈与架构

- **开发语言**：C++17
- **图形框架**：Qt 6.11 (Widgets, Sql, Multimedia)
- **构建系统**：CMake
- **编译器**：MSVC 2022
- **数据库**：SQLite 3

### 🏗️ 核心架构
项目采用**面向对象的模块化设计**，所有悬浮窗均继承自统一的基类 `BaseFloatingWidget`，该基类封装了：
- **无边框拖动**：重写鼠标事件实现窗口移动。
- **全局热键**：支持 `Esc` 一键关闭悬浮窗。
- **通用动画**：统一的窗口出现/隐藏动画接口。
- **数据层分离**：通过 `DatabaseManager` 单例统一管理数据读写，实现了界面与数据的解耦。

## 🚀 快速开始

### 环境要求
- **操作系统**：Windows 10 / 11 (64-bit)
- **Qt 版本**：Qt 6.5 或更高版本 (MSVC 2019/2022)
- **开发工具**：Visual Studio 2022 及 CMake 支持

### 构建步骤
1. **克隆仓库**
   ```bash
   git clone https://github.com/zhou-yin2025/CyberSchedule.git
   ```
2. **打开项目**
   使用 Qt Creator 打开项目根目录下的 `CMakeLists.txt`。
3. **配置套件**
   选择 `Desktop Qt 6.x.x MSVC2022 64bit` 套件。
4. **编译运行**
   点击 Qt Creator 左下角的绿色三角按钮运行。

### 直接使用 (免编译)
如果你只想直接体验，可以前往 [Releases](https://github.com/zhou-yin2025/CyberSchedule/releases) 页面下载最新的 `CyberSchedule_V2_Release.zip`。
1. 解压下载的压缩包。
2. 确保 `data` 文件夹与 `CyberScheduleV2.exe` 在同一目录下。
3. 双击运行 `CyberScheduleV2.exe`。

## 🎨 用户手册

| 操作 | 方法 |
| :--- | :--- |
| **移动窗口** | 鼠标按住悬浮窗任意空白区域拖动 |
| **关闭窗口** | 点击窗口上的关闭按钮，或选中窗口按下 `Esc` 键 |
| **新建任务** | 展开任务栏，点击 `+ 新增` 按钮，或双击任务栏空白区域 |
| **设置番茄钟** | 双击顶部的梯形时间窗口 (HUD) |
| **打开设置** | 展开任务栏，点击右下角的齿轮图标 |
